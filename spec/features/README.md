## Adding a feature

1. Run `/new-feature <slug>` (kebab-case) to scaffold the spec from
   `spec/features/_template.md` at `spec/features/<slug>/<slug>.md`.
2. Pick a short UPPER-CASE prefix (e.g. `CANCEL`) and use it for every
   AC ID in the form `AC-<PREFIX>-<N>`. Same for user stories: `US-<PREFIX>-<N>`.
3. Fill in the spec, then run `/feature` to drive the multi-agent ATDD/TDD loop.
4. AC→test traceability is verified by `scripts/verify-ac-tests.sh` and the
   requirements-reviewer agent at commit time.
